# NKTouch v0.7.4.1 UI/UX

V7.4.1 is the native dark-neon UI/UX polish layer over the retained V7.4 Network/API core.

- Lua Workspace opens directly from Settings; the extra dashboard hop is removed for the normal editing flow.
- Library filters are functional: All / Running / Favorites / Recent.
- Swipe a Lua script to favorite or unfavorite it.
- Recent sorts scripts by modification time.
- Samples creates real Tap / HTTP(S) / explicit OCR scripts and opens them immediately in Editor.
- Editor / Logs / Result tabs stay wired to the existing nkeditor/task engine.
- Save / Check / Run / Stop use the existing V7.4 runtime; Run always syntax-checks first.
- Syntax state is no longer shown as green after an edit until Check succeeds.
- Task status polls the real task engine states (starting/running/paused/stopping/success/failed/stopped/timeout), and the Result tab reflects the real state.
- Lua syntax highlighting and format action remain available.
- AI prompt UX currently creates a local Lua draft scaffold; it does not silently execute generated code.
- Network/API, JSON, task engine, recorder and bundle behavior remain inherited from V7.4/V7.3.
