# NKTouch 0.7.5.2 — Recorder V3

Baseline: Sileo 0.7.5.1 / app 7.4.7 Daily Driver.

Recorder V3 adds real HID multi-segment Record/Pause/Resume/Stop, editable `.nktl` timelines, action type/timing/coordinate/order editing, replay through `nktask`, and one-tap conversion into managed Lua scripts.

The direct `nktask -> lua54` runtime baseline remains unchanged.
